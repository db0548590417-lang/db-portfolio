# דקל AI — סטודיו לעיצוב וקריאייטיב

ממשק React ושרת Node.js עם הרשמה פתוחה באמצעות שם משתמש וסיסמה, בתוך העיצוב של דקל AI.
אין צורך ב-Google OAuth ואין חלון סיסמה של Chrome.

## הרשמה וחשבונות

- שם משתמש ייחודי: 3–32 אותיות, מספרים, נקודה, קו או קו תחתון; נתמכת עברית. אותיות גדולות וקטנות באנגלית נחשבות לאותו שם.
- סיסמה: 12–128 תווים. הסיסמאות נשמרות כגיבוב scrypt עם מלח אקראי נפרד, ולא כטקסט גלוי.
- ההתחברות נשמרת בעוגייה מוצפנת HttpOnly/Secure למשך 30 יום. היציאה מוחקת את עוגיות ההתחברות והמפתח.
- כל משתמש מחבר מפתח Gemini משלו. המפתח מוצפן, מקושר למזהה החשבון ואינו מוחזר בסטטוס API.
- הפרויקטים, ההעדפות ותמונות העיצוב נשמרים בדפדפן בנפרד לפי החשבון. אין כרגע סנכרון ענן, שחזור סיסמה או מנויים.

## פרסום ב-Render

render.yaml מגדיר שירות Node בתוכנית free ומסד Postgres בשם dekel-ai-accounts בתוכנית free.
ניסיון המסד החינמי אושר על ידי בעל הפרויקט ל-30 יום. אין כאן שדרוג אוטומטי לתשלום.
לפי מדיניות Render, המסד החינמי פג לאחר 30 יום; נדרש לשדרג או להעביר את הנתונים כדי להמשיך להשתמש בחשבונות.

DATABASE_URL מקושר אוטומטית למסד דרך ה-Blueprint. הקוד יוצר את טבלת החשבונות בהפעלה הראשונה.
עד שמסד הנתונים מוכן, הרשמה וכניסה לחשבונות חדשות חסומות כדי שלא ייווצרו חשבונות זמניים שאובדים בהפעלה מחדש.
בעל הסטודיו יכול להמשיך להיכנס בטופס בעל הסטודיו עם APP_ACCESS_PASSWORD הקיימת. נתוניו המקומיים נשמרים.

הפעל סנכרון של ה-Blueprint הקיים ב-Render אם העדכון אינו מתבצע אוטומטית. אין צורך ליצור Blueprint כפול.
לאחר סיום יצירת המסד ובניית השירות, רענן את האתר ובדוק הרשמה, יציאה וכניסה מחדש.

משתני סביבה:
- APP_SESSION_SECRET: מיוצר ונשמר ב-Render. אין לשנות ללא צורך, כי שינוי מנתק את כל המשתמשים.
- APP_ACCESS_PASSWORD: סיסמת בעל הסטודיו הקיימת; אינה סיסמת המשתמשים.
- DATABASE_URL: כתובת Postgres, המסופקת על ידי Render. אין לשתף או להכניס לקוד.
- NODE_VERSION: 24.

## פיתוח ובדיקות

```sh
npm install
npm run build
node verify-render.mjs
node verify-web.mjs
npm start
```

לבדיקה מקומית אפשר להגדיר ACCOUNTS_SQLITE_PATH תחת .local-data ולהשתמש ב-SQLite המובנה ב-Node 24.
ב-Render משתמשים ב-Postgres בלבד; הקוד אינו שומר את החשבונות בדיסק הזמני של השירות החינמי.

הבדיקות בודקות הרשמה, התחברות חוזרת לאחר פתיחת מסד מחדש, ייחודיות שמות, גיבוב סיסמאות, CSRF, הפרדת מפתחות ויציאה.
הבדיקות המקומיות משתמשות ב-SQLite; החיבור למסד Postgres האמיתי והפרסום דורשים אימות ב-Render.
בדיקת TypeScript המלאה כוללת עדיין שגיאות קיימות במודולים הישנים.

הגרסה הישנה של אתר הפורטפוליו נשמרה בענף backup-before-dekel-ai-2026-10-23.

מדיניות המסד החינמי: https://render.com/docs/free#free-postgres

## עדכון ממשק והדרכת פתיחה

שופרה קריאות הכיתובים והניגודיות במסכים הגלויים; תוקן כלל צבע שחולל טקסט כהה על רקעים שקופים.
הוסרו תגי פיתוח, אבחון וכניסת בעלים נפרדת. הבעלים ממשיך להיכנס בטופס הרגיל עם שם המשתמש dekel והסיסמה הקיימת.
הגדרת Gemini נמצאת בהגדרות > חיבור AI, ללא חלונית אוטומטית או כפתור צף. עזרה טכנית נמצאת בפרטים סגורים לפי דרישה.
נוסף סיור פתיחה קצר בארבעה שלבים, שנשמר בנפרד לכל חשבון ודפדפן; ניתן לפתוח אותו שוב דרך סיור בכלים.
פאנל המאפיינים מתחיל מכווץ כדי להשאיר מקום לעבודה; אפשר לפתוח אותו או להשתמש בעריכת פרויקט.

נבדקו בדפדפן הרשמה, פתיחה חד-פעמית של הסיור, דילוג/סיום/פתיחה חוזרת, ניווט לעשרת הכלים, הגדרת חיבור, תצוגת 390px והיעדר שגיאות JavaScript.
בדיקת ניגודיות לטקסט גלוי במסכי ברירת המחדל לא מצאה חריגות ביחס 4.5:1 לטקסט רגיל (3:1 לטקסט גדול). זו בדיקה מוגבלת למסכים ולמצבים שנבדקו ואינה הצהרת תאימות נגישות מלאה.
הסברים חיוניים על שמירה, חיוב וסוגי קבצים נשארו בהגדרות או במקומות הרלוונטיים.
