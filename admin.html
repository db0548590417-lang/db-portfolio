חזרה לגלריה

כאן מכינים את הגלריה. השינויים נשארים בעמוד הזה בלבד, עד שתוריד את הקובץ ותעלה אותו לגיטהאב.

  1. הוסף או ערוך עבודות.
  2. לחץ על ״הורדת קובץ הגלריה״. התמונות כלולות בקובץ.
  3. במאגר שלך בגיטהאב, בחר Add file → Upload files, העלה את projects.json ואשר עם Commit changes.

רק מי שיש לו הרשאת כתיבה במאגר יכול לפרסם שינויים. העמוד הזה אינו מפרסם בעצמו.
